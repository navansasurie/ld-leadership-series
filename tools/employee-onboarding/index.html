Milestone reviews

Structured manager–employee conversations at days 30, 60 and 90.

Reviews should assess observable work, employee experience and support needs—not only completion. Notes are saved in this browser.

Conversation guide

Use these questions during each milestone review.

Day 30 · Belonging and orientation

Can the employee explain their role, find support, navigate essential tools and describe how the team works? What still feels unclear?

Day 60 · Capability and application

Which core tasks can the employee perform with limited support? What errors or dependencies remain? What coaching or practice is needed?

Day 90 · Independence and growth

Can the employee deliver agreed role outcomes independently? What should the next development plan include?

Data & privacy

This is a standalone offline-capable file. Employee information is stored in this browser's local storage, not sent to a server. Export JSON to back up or transfer a programme. Browser data can be lost when storage is cleared, and local storage is not suitable for sensitive HR records or shared-device access.

Use one browser profile or one exported file per employee. This template does not provide authentication, multi-user collaboration or centralized HRIS integration.
