# The L&D Leadership Series — GitHub Pages starter

Professional portfolio for Navaneethakrishnan A.

## Publish
1. Create a **public** GitHub repository named `ld-leadership-series` (or any available name).
2. Upload **the contents of this folder** to the repository root, preserving `articles/day-01/index.html` and `assets/author.jpg`.
3. Go to **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
4. Choose `main`, `/(root)`, then **Save**.
5. Once deployed, open `https://YOUR-USERNAME.github.io/ld-leadership-series/` and check the Day 01 link and contact buttons.

For a repository named `YOUR-USERNAME.github.io`, the address is `https://YOUR-USERNAME.github.io/` instead.

## Add Day 02 onward
Create `articles/day-02/index.html` for Day 02. Add a new article card on the home page linking to `articles/day-02/`. Repeat for future days. Only publish fictional or authorized material; GitHub Pages is public.
